================================================================
 neo_pcrypt  -  Neo Geo PVC系 P-ROM 暗号化・分割ツール
================================================================

復号済みのP-ROMを、MAME用の暗号化済み p1 / p2 (/ p3) に変換するツールです。
逆に、暗号化済みの p1 / p2 (/ p3) から復号済みP-ROMに戻すこともできます。
P-ROMのみが対象です (グラフィックやサウンドのROMは扱いません)。

GUI (ウィンドウ画面) とコマンドラインの両方で使えます。


----------------------------------------------------------------
 1. 対応セット
----------------------------------------------------------------

 セット名    表示                               入力サイズ  出力ファイル名
 ---------   --------------------------------   ---------   ---------------------------
 kof2003     KOF2003 (MVS)                      9MB         271-p1c.p1 / 271-p2c.p2 / 271-p3c.p3
 kof2003h    KOF2003 (AES)                      9MB         271-p1k.p1 / 271-p2k.p2 / 271-p3k.p3
 svc         SVC CHAOS (MVS/AES)                8MB         269-p1.p1  / 269-p2.p2
 svcpcba     SVC CHAOS (JAMMA PCB set 2)        8MB         269-p1a.p1 / 269-p2a.p2
 mslug5      Metal Slug 5 (MVS)                 8MB         268-p1cr.p1 / 268-p2cr.p2
 mslug5h     Metal Slug 5 (AES)                 8MB         268-p1c.p1  / 268-p2c.p2

 ※ メタルスラッグ5は、MVS版と家庭用(AES)版で暗号化ルーチンは同じです。
 ※ svcpcba は svc と同じ暗号化ルーチンで、出力ファイル名だけが異なります。
 ※ 出力ファイル名は、GUIの入力欄または --names で変更できます。


----------------------------------------------------------------
 2. 動作環境
----------------------------------------------------------------

 ・Python 3 (標準ライブラリだけで動作します。追加のインストールは不要です)
 ・GUIには tkinter が必要です (通常のPythonに同梱されています)


----------------------------------------------------------------
 3. GUIの使い方
----------------------------------------------------------------

 引数なしで起動します。

     python neo_pcrypt.py

 【暗号化】 復号済みP-ROM -> p1 / p2 / p3
  1. 「対象セット」を選びます。出力ファイル名が自動で入ります。
  2. 「入力ファイル」に、復号済みP-ROMを選びます。
  3. 「出力先」を選びます。空欄なら入力ファイルと同じフォルダです。
  4. 「入力バイト順」は、通常は auto のままで構いません。
  5. 「変換開始」を押します。結果はログ欄に表示されます。

 【復号】 p1 / p2 / p3 -> 復号済みP-ROM
  1. 「復号モードにする」にチェックを入れます。
  2. 「入力ファイル」に p1、「入力 p2」に p2 を選びます。
     KOF2003のときは「入力 p3」に p3 も選びます。
  3. 「出力ファイル名」と「出力バイト順」を決めます。
  4. 「復号開始」を押します。


----------------------------------------------------------------
 4. コマンドラインの使い方
----------------------------------------------------------------

 【暗号化】
     python neo_pcrypt.py <セット名> <復号済みP-ROM> [-o 出力先フォルダ]

     例) python neo_pcrypt.py kof2003h decrypted.bin -o out
         python neo_pcrypt.py svc      decrypted.bin

 【復号】 -d を付けて、ファイルを p1 p2 [p3] の順に指定します。
     例) python neo_pcrypt.py kof2003 -d 271-p1c.p1 271-p2c.p2 271-p3c.p3 -o out
         python neo_pcrypt.py mslug5  -d 268-p1cr.p1 268-p2cr.p2 --out-order le

 【主なオプション】
     -o, --outdir DIR      出力先フォルダ
     --order auto|be|le    入力のバイト順 (既定: auto)
     --no-swap-out         出力直前の2バイトスワップを行わない
     --names p1,p2[,p3]    出力ファイル名を指定
     --crc a,b[,c]         期待CRC32を16進で指定 (内蔵値の代わりに使う)
     --layout mame|complete  入力(復号時は出力)の並び (後述)
     --no-verify           往復検証を省略
     -d, --decrypt         復号モード
     --no-swap-in          [復号時] 入力が2バイトスワップ済みでない場合に指定
     --out-order be|le     [復号時] 出力のバイト順 (既定: be)
     --outname NAME        [復号時] 出力ファイル名


----------------------------------------------------------------
 5. 入力ファイルについて
----------------------------------------------------------------

 ■ 通常の入力 (--layout mame / 既定)
   MAMEが復号した直後の、メインCPUメモリそのままの内容です。
     KOF2003系 ... 9MB (先頭1MBは固定領域、次の1MBが p3 相当、残りが p1/p2 相当)
     SVC / MS5  ... 8MB
   バイト順は、68000ネイティブ (先頭 00 10 F3 00) とワードスワップ
   (先頭 10 00 00 F3) のどちらも自動判別します。

 ■ 出力のバイト順
   暗号化済みファイルは、書き出す直前に2バイト(16bitワード)単位で
   入れ替えています。これは常に行われます (CLIの --no-swap-out で無効化できます)。


----------------------------------------------------------------
 6. メタルスラッグ5 (MVS) 専用機能
----------------------------------------------------------------

 メタルスラッグ5 (mslug5) だけで、次の機能を使えます。
 他のセットで指定するとエラーになります。

 ■ --layout complete  (入力レイアウト: 268-p1d.bin 形式)
   メタルスラッグ コンプリート版のメタルスラッグ5用P-ROM (268-p1d.bin) と
   同じ並びのファイルを入力にできます。
     ・サイズは 5MB 〜 8MB (足りない分は 0xFF で補います)
     ・バイト順は、先頭 10 00 00 F3 のワードスワップ形式
   復号モードでは、同じ並びのファイルを出力します。

 ■ ROMの内容を書き換えるオプション (暗号化時のみ)
     --ms5-aesfix    0x122A の AES Fix を除去するパッチを当てる
     --ms5-fillff    0x500000〜0x7FFFFF を 0xFF で埋める   (complete のときだけ)
     --ms5-autofix   RAM保存・bootleg形式の並びを自動で補正 (complete のときだけ)
     --iq-compat     --layout complete と、上の3つをまとめて有効にする

   ※ これらを使うとデータが変わるため、正規ROMのCRC32・SHA1とは一致しません。

   例) python neo_pcrypt.py mslug5 268-p1d.bin --iq-compat -o out

 8. 注意事項
----------------------------------------------------------------

 ・このツールにROMのデータは含まれていません。変換に使うROMは、
   ご自身で正当に入手したものをお使いください。
 ・復号済みROMの配布、および暗号化済みROMの配布は、
   著作権者の権利を侵害するおそれがあります。行わないでください。
 ・データを書き換えるオプション (6章) を使った出力は、正規ROMとは別物です。
 ・本ツールの使用によって生じたいかなる損害についても、作者は責任を負いません。
