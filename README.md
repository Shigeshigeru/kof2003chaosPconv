# kof2003chaosPconv
kof2003(AES,MVS) svc chaos mslug5 PROM Encryption tools

AIの力によりMAMEのソースコードから新規で作り直しました

対応ゲームは  
kof2003(AES,MVS),Metal Slug 5(AES,MVS),SVC Chaos(AES,MVS,JAMMA2)  
PROMのみの対応になります  
その他のCROM等はscrap_aさんのneo-cmcで変換できるので  
よろしくお願いいたします  
(理屈上まとめて変換等も出来ますが必要なら自分で作ってください)  

あくまで以前のツールを新規でまとめたものになります  
以前のものと作成されるものは同じですが  
復号機能も実装しました!!   
(*.neo変換の足がかりや研究、実験用)  
逆変換したら判明するので復号ファイル出力機能にはCRC確認機能等ありません  

**大事なこと**  
IQさんのはメタスラコンプリート版(海賊版)の変換に必要なので  
並び替えやパッチの追加を使用できるようにしました  
(MVS版の暗号化時のみ有効)  
この実装の都合上なんとなくメタスラ5の  
JAMMA版PROMの作成を削除しましたが  
MVS版と名前が違うだけなので  
ご面倒ですがリネームして使用してください  
SVCは同じ動作でJAMMA set 2に対応してます  
CRC優先で読んでくれるエミュレーターなら特に問題ないです
